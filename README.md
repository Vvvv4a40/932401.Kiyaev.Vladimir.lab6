# Лабораторная работа №6

Вариант 12 — сервер с фиктивными курсами USD, EUR и CNY за неделю. На странице можно переключать валюту, смотреть график, список значений и средний курс.

## Запуск

```bash
npm install
npm start
```

После запуска сайт будет доступен по адресу `http://localhost:3000`.

## Маршруты

- `GET /` — главная страница;
- `GET /about` — информация о работе;
- `GET /api/rates/:currency` — семь значений и средний курс для USD, EUR или CNY.

Для неизвестной валюты API возвращает статус 404. Query-параметры не влияют на ответ.

## Проверка

```bash
npm test
```

Приложение содержит манифест и service worker, поэтому после первого открытия работает без подключения к сети.
