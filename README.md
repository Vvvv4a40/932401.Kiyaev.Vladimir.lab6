# Лабораторная работа №6

Вариант 12 — сервер на C# и ASP.NET Core (.NET 10) с фиктивными курсами USD, EUR и CNY за неделю. На странице можно переключать валюту, смотреть график, список значений и средний курс.

## Запуск

Требуется .NET SDK 10. Node.js и npm не нужны.

```bash
dotnet run --project Lab6.csproj
```

После запуска сайт будет доступен по адресу `http://localhost:3000`.

Другой адрес можно указать через `dotnet run --project Lab6.csproj -- --urls http://localhost:3006`, переменную `ASPNETCORE_URLS` или `PORT`. Параметр `--urls` и `ASPNETCORE_URLS` имеют приоритет над `PORT`.

## Маршруты

- `GET /` — главная страница;
- `GET /about` — информация о работе;
- `GET /api/rates/:currency` — семь значений и средний курс для USD, EUR или CNY.

Для неизвестной валюты API возвращает статус 404. Query-параметры не влияют на ответ.

## Проверка

```bash
dotnet run --project tests/Lab6.Tests.csproj
```

Проверки поднимают настоящий HTTP-сервер на свободном порту и проверяют все валюты, средние значения, регистр, query-параметры, ошибки, страницы и файлы PWA. Дополнительные тестовые пакеты не требуются.

## Сборка для публикации

```bash
dotnet publish Lab6.csproj -c Release -o publish
dotnet publish/Lab6.dll
```

Приложение содержит манифест и service worker, поэтому после первого открытия работает без подключения к сети.
