# Лабораторная работа №6

Вариант 12. Курсы USD, EUR и CNY за неделю. Данные заданы в коде, на странице есть график и средний курс. После первого открытия данные кешируются для работы без интернета.

Сервер на C# и ASP.NET Core. Нужен .NET SDK 10.

## Запуск

В папке лабораторной:

```sh
dotnet run
```

Открыть [localhost:3000](http://localhost:3000).

API: `GET /api/rates/USD`. Вместо USD можно указать EUR или CNY. Страница о работе — `/about`.

## Тесты

```sh
dotnet run --project tests/Lab6.Tests.csproj
```
